PART1 
깃 - 버전관리 시스템
깃허브 - 버전을 보관하는곳

1.깃에는 파일을 하나만 넣거나 모두 넣어야함
2. Staging area에 넣음
3. Staging area 를 통재로 복사해서 버전으로 추가

working directory - staging area - repository

!!!!!!시작!!!!!!!
git config --global user.name "Your Name"
git config --global user.email "Your Email"
git config --global init.defaultBranch main

`--global` 옵션은 Git 설정을 현재 사용자 계정 전반에 적용하여, 해당 사용자의 어떤 저장소에서든 기본값으로 사용되게 합니다.


0) 폴더생성
1) git init 
2) git add 파일명
  > git add 파일명
  > git add .   (전체 다 올리는거)
 
3) git commit
  > git commit -m "커밋로그"
4) git log - 로그보기

====================================
현재 워킹디렉토리와, 스테이지 에어리어가 무슨 버전인지
표기로 남겨둬야함
> HEAD : 헤드가 이 커밋을 가르키고 있다.

git checkout "commitid" or get checkout "상대위치"
> HEAD가 해당 버전으로 바뀜 
> HEAD를 바꾸면 Staging area와 working directory 도 바뀜
> HEAD~1, HEAD~2,......  

부모커밋
====================================
git status
수정상태 대상 구하기
> tracked 상태와 staging area간의 차이점
> staging과 repository간의 차이점
> untracked 상태에 있는 파일

====================================
git diff
> tracked와 staging area간의 차이점을 보여줌
> git diff [커밋ID]   // working directory와 커밋상태와의 차이
> git diff --cashed  // staging area와 repository와 차이점
