부모커밋
====================================
git status
수정상태 대상 구하기
> tracked 상태와 staging area간의 차이점
> staging과 repository간의 차이점
> untracked 상태에 있는 파일

====================================
git diff
> tracked와 staging area간의 차이점을 보여줌
> git diff 커밋ID or git diff head   
   // working directory와 커밋상태와의 차이
> git diff --cached  // staging area와 repository와 차이점
> git diff 커밋id1 커밋id2
  ex) git diff head~1 head

PUSH : 로컬 repository -> 리모트 repository
> git push [별칭] [로컬 브랜치] : [리모트에 저장될 브랜치]
ex) git push origin main
ex) git push origin test
ex) git push origin main:develop
* 브랜치에 올리거나 덮어씀
* 로컬브랜치 >= 리모트브랜치 일때만 커밋가능

>git push 
- 현재 checkout된 브랜치만 푸시
- 트래킹브랜치가 있는경우

FETCH
> 
트래킹 브랜치 (ex. origin/main)
일반    브랜치 (ex. main)
* 트래킹 브랜치는 체크아웃이나 커밋불가, 브랜치 범위를 알려주는 역할만함

git fetch origin main   //리모트에 있는 브랜치를 로컬의 트래킹브랜치로 복사하거나 덮어씌움
git branch -r (트래킹브랜치 조회)
