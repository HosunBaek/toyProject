`--global` 옵션은 Git 설정을 현재 사용자 계정 전반에 적용하여, 해당 사용자의 어떤 저장소에서든 기본값으로 사용되게 합니다.


0) 폴더생성
1) git init 
2) git add 파일명
  > git add 파일명
  > git add .   (전체 다 올리는거)
 
3) git commit
  > git commit -m "커밋로그"
  > git commit -am "커밋로그"
4) git log - 로그보기
  > git log --graph --all

표기로 남겨둬야함

git checkout "commitid" or get checkout "상대위치"
> HEAD가 해당 버전으로 바뀜 
> HEAD를 바꾸면 Staging area와 working directory 도 바뀜
> HEAD~1, HEAD~2,......  

부모커밋
====================================
git status
수정상태 대상 구하기
> tracked 상태와 staging area간의 차이점
> staging과 repository간의 차이점
> untracked 상태에 있는 파일

====================================
git diff
> tracked와 staging area간의 차이점을 보여줌
> git diff 커밋ID or git diff head   
   // working directory와 커밋상태와의 차이
> git diff --cached  // staging area와 repository와 차이점
> git diff 커밋id1 커밋id2
  ex) git diff head~1 head

1)3WAY -MERGE

체리픽 - 특정 커밋 하나만 메인브런치로 가져옴
cherry-pick
>git cherry-pick 아이디
체리픽시 충돌
1) git add "수정이 완료된 파일"
2) git cherry-pick --continue     : 체리픽 후 커밋
   git  cherry-pick --abort          : 체리픽 취소
